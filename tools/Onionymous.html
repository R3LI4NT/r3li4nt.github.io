FEATURES CARACTERÍSTICAS

Everything you need to route through Tor Todo lo necesario para enrutarte por Tor

The official Tor binary, pluggable transports, Wintun driver and sing-box engine are all embedded in a single portable executable. El binario oficial de Tor, pluggable transports, driver Wintun y motor sing-box vienen embebidos en un único ejecutable portable.

TUN/VPN Mode Modo TUN/VPN NEW

System-wide routing through Tor — not just proxy-aware apps. Any program goes through Tor when this mode is active. Routing de todo el sistema a través de Tor — no solo apps proxy-aware. Cualquier programa pasa por Tor con este modo activo.

  • Wintun (WireGuard's TUN driver) + sing-box engine, both embedded
  • Wintun (driver TUN de WireGuard) + motor sing-box, embebidos
  • Automatic admin detection with graceful fallback to Proxy
  • Detección automática de admin con fallback a Proxy
  • Pre-resolved DNS through Tor to prevent leaks
  • DNS pre-resuelto vía Tor para evitar leaks
  • Robust cleanup — adapter destroyed on disconnect
  • Cleanup robusto — adaptador destruido al desconectar

Smarter Exit Selector Selector de salida inteligente NEW

Visual availability indicators per country, plus automatic detection when an exit country has no operational nodes. Indicadores visuales de disponibilidad por país, más detección automática cuando un país no tiene exit nodes operativos.

  • ★ High availability (DE, NL, US, FR, CH...)Alta disponibilidad (DE, NL, US, FR, CH...)
  • ⚠ Few nodes — may fail (PT, AR, IL, MX...)Pocos nodos — puede fallar (PT, AR, IL, MX...)
  • Auto banner when "all routers down" detectedBanner automático al detectar "all routers down"

Click-the-Orb UX UX click-en-el-orb

The central animated circle is the connect/disconnect button. Live bootstrap progress painted as a filled arc around it. El círculo animado central es el botón de conectar/desconectar. Progreso de bootstrap pintado como arco alrededor.

Kill Switch

Blocks all non-Tor traffic at the OS level via Windows Defender Firewall. Auto-torn down on disconnect — you're never left without internet. Bloquea todo el tráfico no-Tor a nivel OS vía Windows Defender. Se desactiva al desconectar — nunca te quedás sin internet.

Bridges & Transports Puentes y transports

Built-in obfs4 with rotating bridges + custom bridge support for paste-your-own lines from bridges.torproject.org. obfs4 incorporado con bridges rotantes + soporte de puentes personalizados para pegar líneas de bridges.torproject.org.

Live observability Observabilidad en vivo

Real-time bandwidth sparkline, session totals, full event log filtered by source and level. Public IP in amber updated on every identity rotation. Sparkline de ancho de banda en vivo, totales de sesión, log completo filtrable. IP pública en ámbar actualizada en cada rotación de identidad.

Tor auto-updater Auto-updater de Tor

Downloads the latest Tor Expert Bundle from archive.torproject.org, verifies SHA-256 against the signed manifest, installs atomically. Descarga el Tor Expert Bundle más reciente desde archive.torproject.org, verifica SHA-256 contra el manifiesto firmado, instala atómicamente.

Polished UI UI cuidada

Custom violet theme with DWM Mica/Acrylic blur, Phosphor icons throughout, synthesized UI sounds (no audio files bundled), bilingual EN/ES at runtime. Tema violeta propio con blur DWM Mica/Acrylic, iconos Phosphor, sonidos UI sintetizados (sin archivos de audio), bilingüe EN/ES en tiempo real.

True portability Portabilidad real

The .exe extracts its embedded runtime on first launch and runs from cache afterwards. Move it anywhere — it still works. El .exe extrae su runtime embebido en el primer arranque y corre desde cache. Movelo donde quieras — sigue funcionando.

Live chart with violet download / amber upload, 60-sample rolling window. Session totals for bytes read/written.Gráfico en vivo con descarga violeta / subida ámbar, ventana rolante de 60 muestras. Totales de sesión.

Full event logRegistro completo

Combined Tor + app events, filterable by source and level, with auto-scroll to the tail.Eventos Tor + app combinados, filtrable por origen y nivel, con auto-scroll al pie.

Synthesized soundsSonidos sintetizados
